# Política clean-room — Verbo no Chão

Estado: `APPROVED`

O Verbo no Chão é um projeto independente.

É proibido reutilizar, copiar, importar ou misturar:

- conteúdo narrativo, personagens, episódios ou identidade do Because Of This Stories;
- prompts, contratos, travas, presets, vozes, trilhas, imagens ou vídeos do Because Of This;
- código operacional, dados, histórico de produção ou fluxos editoriais do Because Of This;
- decisões de branding ou linguagem audiovisual que não tenham sido aprovadas especificamente para o Verbo no Chão.

O repositório e os materiais do Because Of This podem ser consultados apenas para pesquisa técnica abstrata, quando isso for expressamente necessário e compatível com os limites do projeto. Nenhum artefato consultado se torna automaticamente parte do Verbo no Chão.

Toda mídia e todo conteúdo do canal devem nascer de briefing, roteiro, fontes bíblicas, licenças e decisões próprias do Verbo no Chão, com rastreabilidade no GitHub.

Qualquer exceção exige aprovação explícita do proprietário antes da utilização.
