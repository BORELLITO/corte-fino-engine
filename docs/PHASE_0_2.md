# Fase 0.2 — Contratos editoriais e direitos

Objetivo: impedir que um pacote editorial avance sem base bíblica identificável, separação entre texto e interpretação, aplicação responsável, originalidade declarada e comprovação de direitos comerciais.

Implementado:

- contrato editorial estruturado;
- contrato de validação bíblica;
- contrato de direitos autorais;
- validações determinísticas fail-closed;
- testes de casos aprovados e bloqueados.

Limites mantidos:

- nenhuma geração de mídia;
- nenhum acesso a APIs externas;
- nenhum segredo;
- nenhuma publicação;
- nenhuma alteração da branch principal.
